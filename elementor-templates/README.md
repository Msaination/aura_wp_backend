# Aura Spa Elementor Section Templates

These seven Elementor JSON templates split the homepage at `http://localhost:8888/AuraDev/backend/` into the hero/navigation, five content sections, and footer. Each template contains the original section markup and its matching inline styles so it can be imported on its own.

## Import

In WordPress, open **Templates → Saved Templates → Import Templates**, then import each JSON file. Add them to a page in this order:

1. Hero and Navigation
2. Welcome
3. The Aura Experience
4. Offerings
5. Events
6. Contact and EFT Payment
7. Footer

The sections use Elementor HTML widgets to preserve the source layout closely. Their markup and style tags remain editable in each widget. The footer template includes the responsive navigation, reveal animation, and copyright-year script.
